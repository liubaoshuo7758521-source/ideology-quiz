## 🚀 快速开始

### 方式1：直接打开（推荐）

1. 下载整个项目文件夹
2. 双击打开 `index.html` 文件
3. 在浏览器中即可使用

### 方式2：本地服务器（可选）

```bash
# 使用Python启动本地服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

然后访问: `http://localhost:8000`
